# 标准三重开发测试与交付工作流规范

本规范定义了本工程在进行功能迭代、性能优化或 Bug 修复后的**标准交付验证流程与最佳实践**。
任何特性的交付必须同时满足以下三维要求，并完成闭环排查。

---

## 核心交付原则

1. **绝不占用或依赖用户的终端服务**：
   - 严禁依赖用户手动运行的端口（如 `61302`）或要求用户协助重启；
   - 自动化测试时，必须在后台**独立启动专属测试端口（如 `--port 61303`）**，测试完毕自动停止清理。
2. **前后端日志闭环验证**：
   - 后端：必须捕获启动预热日志、请求路由状态码与耗时打点；
   - 前端：必须通过 DevTools 验证 Console 零报错（无 Uncaught Error/Warning）与 Network 请求正常（200 OK）。
3. **真实浏览器端到端交互**：
   - 必须使用 `browser_subagent` 模拟真实用户行为，验证 DOM 渲染、滚动翻页、表单保存、弹窗与多页面联动，并留存 WebP 录屏。
4. **Windows 大库性能铁律**：
   - 严禁在资产循环中调用 `Path.resolve()` 或未缓存的正则编译，必须使用 `os.scandir` 与规范化 posix 字符串切片；
   - 启动时通过 FastAPI `lifespan` 预热全局检索索引，保证前端首屏毫秒级秒开。

---

## 标准执行四步法（Runbook）

### 第 1 步：代码与业务逻辑测试（Code Tests）
在工作区目录下运行全量自动化测试套件：
```powershell
uv run pytest -q
```
- 确保所有测试项（单元测试、向下兼容测试、接口契约测试）100% 通过（0 failed）。

---

### 第 2 步：后台独立启动测试实例（Isolated Server）
使用独立隔离端口启动测试服务（例如 61303），并记录任务 ID：
```powershell
uv run publishing-workspace web G:\ai_publish --host 127.0.0.1 --port 61303 --log-level info
```
- **检查启动日志**：
  - 确认 `Web 正在预热素材检索索引...` 正常触发；
  - 确认 `Web 检索索引预热完成 (耗时: xx s)`；
  - 确认 `Uvicorn running on http://127.0.0.1:61303`。

---

### 第 3 步：调用 Browser Subagent 进行端到端交互测试（Browser Tests）
启动 `browser_subagent` 访问 `http://127.0.0.1:61303`：
- **测试目标清单**：
  1. **瀑布流首屏渲染**：访问 `/library`，验证素材瀑布流秒开渲染（卡片、缩略图、尺寸信息、格式角标）；
  2. **无限滚动加载**：向下滚动触发 `IntersectionObserver` 无缝加载下一页；
  3. **节点模糊联想与筛选**：输入标签关键字，验证下拉列表不出现 `undefined`，点击后正确填入并过滤素材；
  4. **清除按钮行为**：输入内容时显示单清除按钮（无原生重复 ✕ 符号），点击后清空输入并重置列表；
  5. **素材多选与投稿集合**：勾选多张素材，验证右侧面板和已选角标计数同步联动；
  6. **大图预览 Dialog**：点击素材卡片弹出高清预览，验证右上角关闭与 ESC 退出；
  7. **双页面导航联动**：切换至 `/calendar` 排期视图，验证月历网格与投稿任务渲染，再切回 `/library` 确认状态平滑无白屏。
- **输出成果**：自动生成操作过程的 WebP 动画录屏。

---

### 第 4 步：前后端日志闭环检查与清理（Logs & Cleanup）
1. **前端日志核验**：
   - 检查浏览器子代理输出的 Console 日志，确保无 `Uncaught TypeError` 或脚本语法警告；
   - 检查 Network 接口响应，确保 `/api/library/assets`、`/api/library/facets`、`/api/assets/.../preview` 均返回 200 OK。
2. **后端日志核验**：
   - 检查后台终端日志，确认接口响应时延均在毫秒级（< 10ms），无未捕获异常堆栈。
3. **清理测试进程**：
   - 使用 `manage_task` 工具结束后台运行的 61303 测试服务进程，释放端口与系统资源。
4. **交付汇总**：
   - 向用户清晰汇报：代码测试结果、独立端口运行状态、浏览器测试详情、日志排查结论与录屏地址。
