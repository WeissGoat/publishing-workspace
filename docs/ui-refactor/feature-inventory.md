# Web UI 重构：功能清单与对齐验收

旧前端：`web/static/library.{html,js,css}`（素材库与投稿）、`web/static/calendar.{html,js,css}`（月度计划）。
`schedule.{html,js,css}` 仅在 `calendar.html` 缺失时作为回退，已不在使用中，不迁移；`/schedule.html` 现重定向到 `/calendar`。
旧前端文件已全部删除。

新前端：`frontend/`（Vue 3 + Vite + TypeScript），构建产物输出到 `src/publishing_workspace/web/static/app/`，
由 FastAPI 以 SPA 方式在 `/`、`/library`、`/calendar` 提供服务。运行时不需要 Node。

勾选表示新前端已实现并验证。

## 旧前端中的已知缺陷（新前端直接修正）

- 素材库「刷新」按钮引用了未定义的 `snapshotCache`，点击即报错。
- 日历「立即发布」请求了不存在的 `/api/submissions/{id}/publish`，应为 `/publish/pixiv`。
- 批量打标签使用 `prompt()`，改为对话框。
